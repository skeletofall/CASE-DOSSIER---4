# 💻 Case #4: Guest Network Reconnaissance – Electronics Store (DNS)

**Date:** August 2026  
**Objective:** Assess the security of the guest Wi‑Fi network in an electronics retail store and identify any exposed internal services.

---

## 🧰 Tools

- Termux (Android)
- nmap, ping, curl, telnet, nc, dig

---

## 📋 Tasks

- Connect to the guest network.
- Identify gateway and local subnet.
- Discover active hosts and open ports.
- Investigate web services and captive portal behavior.
- Test for possible administrative access.

---

## 🧠 Outcome

- Large subnet with numerous active hosts discovered.
- Gateway configured with an Eltex captive portal.
- All HTTP traffic redirected to the portal.
- No administrative interfaces were accessible without authentication.

---

## 📎 Status

Completed. No access was performed. Data collected for educational and research purposes.
